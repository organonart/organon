# Neural CA model gallery (#407 Tier B)

Trained **Neural Cellular Automaton** weights for Organon's Field Engine
**"Neural CA (learned surrogate)"** source. Select generator = **Field Engine**,
then the **PDE preset** dropdown → **"Neural CA (Learned)"**. The visual rolls the
NCA out live on a periodic CPU grid, stepped off the PLL beat clock, and renders it
through the existing Field Engine glyph lattice.

`native/deploy.sh` copies `*.json` here into
`~/Library/Application Support/OrganicMath/nca/`, where the editor's
**"Load NCA Model (JSON)…"** dialog opens. With **no** file loaded the runtime uses
a built-in default (`NcaWeights::builtin_default()`), so the source always renders.

## Files

- **`nca-default.json`** — the shipped default: an analytic λ–ω reaction–diffusion
  oscillator, byte-for-byte the same rule as the Rust built-in default. Generated by
  `python3 train.py --demo -o nca-default.json` (stdlib only).

## JSON schema (the runtime contract)

The runtime (`native/src/math.rs` → `NcaWeights` / `NeuralCA`) reads a two-layer MLP
over a **fixed perception**. For every channel it gathers
`[identity, sobel_x, sobel_y, laplacian]` ⇒ input dim `4·channels`, then:

```
hidden = relu(w1 · perception + b1)
delta  = w2 · hidden + b2
state += dt · delta
state  = tanh(state)          # every channel, every step → provably bounded
```

```json
{
  "channels": C,
  "hidden":   H,
  "w1": [ H * (4*C) floats ],   // row-major, perception → hidden
  "b1": [ H floats ],
  "w2": [ C * H floats ],        // row-major, hidden → channel deltas
  "b2": [ C floats ]
}
```

All matrices are **row-major** flat arrays. Every declared dimension is validated on
load; a malformed file is rejected and the built-in default is used instead. The
final `tanh` bounds `|state| ≤ 1` for **any** weights, so a loaded model can never
NaN/blow up the renderer.

Display: channel 0 → density (clamped to [0,1]), channel 1 → hue.

## Training on *The Well*

Real weights are trained **offline** on
[PolymathicAI's *The Well*](https://github.com/PolymathicAI/the_well) — a large
collection of physics simulations (active matter, reaction–diffusion, turbulence, …).
**The Well is licensed CC-BY-4.0**; attribute PolymathicAI when redistributing weights
trained on it.

Recipe (see `train.py :: train_on_the_well` for the wiring):

1. Load a trajectory `U[t, C, H, W]` from the dataset HDF5 (needs `torch` + `h5py`).
2. Build the same fixed perception (identity + Sobel x/y + Laplacian per channel) as
   depthwise conv kernels.
3. Fit `(w1, b1, w2, b2)` so one NCA step predicts the per-step residual
   `U[t+1] − U[t]`, optimizing the multi-step rollout loss (curriculum on horizon) so
   the surrogate stays stable over long autoregressive rollouts.
4. Export in the schema above — no architecture change; the runtime loads it as-is.

```bash
# stdlib-only default (no torch/numpy) — what ships:
python3 train.py --demo -o nca-default.json

# real training (needs torch + h5py + the downloaded dataset):
python3 train.py --dataset active_matter --data /path/to/the_well -o nca-well.json
```

> The **CPU rollout is authoritative.** `native/src/nca.wgsl` is a naga-validated
> (offline) GPU compute path whose dispatch is deferred, exactly as the Field Engine's
> `FieldSim` deferred its GPU route.
